# sidevoice/.github

The Sidevoice organisation's public profile. [`profile/README.md`](profile/README.md) is what GitHub shows at
[github.com/sidevoice](https://github.com/sidevoice); its header, in light and dark versions, is in
[`profile/assets/`](profile/assets).

Images in the profile use paths relative to `profile/`, and links use full `https://github.com/...` addresses, so
they work on the organisation page. Changes go through pull requests.
